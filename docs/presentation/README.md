# FireGuard Demo Presentation

This folder contains the judge-facing FireGuard pitch deck.

## Files

- [fireguard-demo-deck.pptx](fireguard-demo-deck.pptx): PowerPoint deck.
- [contact-sheet.png](contact-sheet.png): rendered contact sheet for quick review.
- [speaker-notes.md](speaker-notes.md): 3-minute talk track.
- [slides](slides): full-resolution slide images.
- [previews](previews): web-sized slide previews.
- [rendered](rendered): previews rendered from the exported deck.
- [source](source): artifact-tool presentation source modules that assemble the PPTX.

## Slide Narrative

1. **FireGuard**: wildfire evacuation orchestration agent.
2. **Coordination gap**: emergency data exists, but it is fragmented.
3. **Signal to action**: Fivetran, Elastic, Routes, Gemini, Validator, Approval, Actions.
4. **Route rejection**: the obvious route is blocked by fire, road, and shelter constraints.
5. **Gemini vs validators**: Gemini plans; deterministic code enforces.
6. **Provider proof**: each integration changes system behavior.
7. **Human approval**: public-facing actions remain gated.
8. **Close**: real feeds become coordinated action.

## Provenance

The slide visuals were generated with GPT Image 2 in the selected light executive style. The PPTX is assembled with artifact-tool presentation source modules, and the exported deck was rendered back to PNG for visual review.

The deck is meant for the hackathon pitch and demo video. It does not replace the repository's transparency ledger or source documentation.
