# FireGuard Transparency Ledger

Last updated: 2026-05-07

This file is the source of truth for what is real, what is simulated, and what still needs to be made production-real. Do not remove or soften an item because it makes the demo look better. Update the status only after code and tests prove the claim.

## Current Truth Summary

FireGuard is a real hosted Cloud Run app with a real FastAPI backend, real Next.js frontend, real Elastic-backed operational memory, a real Fivetran Connector SDK path into BigQuery, source-backed public BC emergency context snapshots, real Vertex Gemini calls, real Twilio allowlisted SMS execution, real GitHub Issues task creation for approved shelter/road/dispatch actions, and real OpenTelemetry span export to a self-hosted Arize Phoenix service on Cloud Run. The self-hosted Phoenix deployment now uses Cloud SQL PostgreSQL, so traces survive Cloud Run replacement. Eval results are exported as Phoenix spans and attached back to those traces as Phoenix `fireguard_eval` annotations. The provided Arize Cloud API key still returns `401` against Phoenix Cloud REST, so Arize Cloud hosted export remains blocked pending a valid Phoenix Cloud key/space.

FireGuard is not yet a fully real emergency orchestration system. The demo-critical evacuation scenario still uses replay and some synthetic operational records, but the evacuation-zone geometry, zone population/home counts, fire evidence, and road-closure evidence are now stored from real source snapshots rather than invented rows. Shelter capacity and resident test contacts can now be updated through named operator check-in endpoints/UI actions; these are real auditable operational inputs, not official public ESS capacity feeds or official resident registries.

## Rule For Future Changes

Every demo claim must be backed by one of:

- a live provider call;
- a stored real source snapshot with provenance;
- a synthetic/simulated label visible in code, API output, and UI.

If none of those is true, the claim does not belong in the demo script.
